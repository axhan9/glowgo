# Glam & Go – statikus bemutató

Ez a WordPress-téma kinézetének és működésének **statikus (HTML + CSS + JS) bemutatója** – csak ügyfél-bemutatóra készült, a projektet nem érinti.

**Működik:** reszponzív elrendezés, sticky fejléc, lenyíló almenü, jobbról beúszó mobilmenü, harmonikás árlista, GYIK, galéria-nagyítás, vissza a tetejére gomb, mobil akciósáv.
**Nem működik (bemutató):** időpontfoglalás (Salonic), űrlap (Fluent Forms), hírlevél (MailPoet), WooCommerce, admin szerkesztés. A gombok a bemutató foglalási oldalára mutatnak.
Az oldalak `noindex` jelölésűek, a keresők nem veszik fel őket.

## Közzététel GitHub Pages-en
1. Hozz létre egy tárolót (repository), töltsd fel a mappa **teljes tartalmát** a gyökérbe.
2. Settings → Pages → *Deploy from a branch* → `main` / `/ (root)`.
3. Pár perc múlva elérhető: `https://FELHASZNÁLÓ.github.io/TÁROLÓ/`.
A betűtípusok (Playfair Display, Lato) a Google Fonts-ról töltődnek be; a képek WebP-k.
